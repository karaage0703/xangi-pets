## 接続する

初回起動時に接続先の追加画面が開きます。名前と xangi のイベント API URL を入力し、その xangi で Web UI も利用するか選びます。

- 同じ Mac の標準構成: `http://localhost:18888`
- 別マシン: LAN または Tailscale から到達できる `http://` / `https://` URL
- Web UI なし: xangi 側で `XANGI_EVENTS_SERVER_ENABLED=true` を設定し、「Web UI も利用する」を OFF

接続先はプロファイルとして保存され、`x` キーまたはメニューの「接続先」から追加・選択・編集・切断できます。複数の xangi-pets を起動した場合も、保存済みプロファイルは共有されます。

「同時に見守るインスタンス」で接続先ごとにON/OFFを選びます。ONのインスタンスには常駐ペットと実行中のセッションペットを表示し、OFFにするとその接続先のペットを閉じます。同じURLのプロファイルは一つのインスタンスとして扱い、設定は再起動後も保持します。

入力先は接続先ボタンで一つ選びます。「保存して接続」はそのインスタンスをONにし、それまでの入力先もONなら見守りを続けます。ほかのインスタンスの常駐ペットは表示専用です。入力先をOFFにした後は、メニューから接続先画面を開いて別の入力先を選べます。未接続のONインスタンスも常駐ペットを表示し、接続を試みます。

「Agent一覧を取得」でAgentを選ぶと、入力先の常駐ペットはそのAgentの会話を表示し、専用セッションへ送信します。同じURLでもAgent別にプロファイルを登録できます。Agentを選ばない「全Agentを見守る」は全イベントを表示し、送信には本体のデフォルト設定を使います。Agent選択には本体のAgent一覧・セッションAPIが必要です。イベントAPIだけの構成では「全Agentを見守る」を使ってください。

xangi-pets は SSE 接続に成功すると「接続済み」、切断時は「再接続中」と表示します。xangi が復帰すると自動で再接続します。

接続先 URL は `http://` または `https://` のみ受け付けます。ユーザー情報を含む URL は拒否し、query と fragment は保存前に取り除きます。

## 基本操作

- ペットをクリック、または `t`: xangi にメッセージを送る
- ドラッグ: ペットを移動する
- 吹き出しをクリック: 吹き出しを閉じる
- `x`: 接続先を選択・設定する
- `p`: 全ペット共通の大きさを切り替える
- `b`: 吹き出しの大きさを切り替える
- `h` または `?`: ヘルプを表示・非表示にする

透明な領域はクリックを背後のアプリへ通します。`1`〜`9` は開発時のアニメーション確認用です。

## メニュー

起動中は macOS のメニューバーに xangi-pets が常駐します。同じ主要操作は、Dock で xangi-pets を選択したときの通常アプリメニューからも利用できます。

- ペットを表示／隠す
- ペットを画面中央に戻す
- xangi に話しかける
- Web Chat をアプリ内または既定ブラウザで開く
- 接続先を設定する
- 通常応答、完了メッセージ、システム通知を切り替える
- ペットと吹き出しの大きさを変える
- ヘルプを表示する／アプリを終了する

自動徘徊や手動配置、モニター構成の変更でペットが画面外へ出た場合は「ペットを画面中央に戻す」を選んでください。起動時にもペットがほとんど見えない位置なら、自動的に現在のモニター中央へ戻ります。

## 通知と吹き出し

通常応答と完了メッセージの吹き出しは別々に切り替えられます。会話中の表示を止めて、完了時だけ確認する使い方もできます。

macOS のシステム通知は初期状態で OFF です。ON にしたあとに開始した応答の完了またはエラーを1回通知します。再接続時に届いた過去イベントは通知しません。最初の通知時に macOS の許可ダイアログが出る場合があります。

長文は 1 ページ 4 行で表示し、応答完了後に 4 秒間隔でページを送ります。最終ページのあと先頭へ戻ります。

## ペットと表示サイズ

ペットの画像はAgentのworkspaceから読み込みます。Agent未指定の常駐ペットは本体のデフォルトAgentの画像を使い、取得できない場合は同梱の`xangi`を表示します。配置方法は[独自ペットを追加する](#独自ペットを追加する)を参照してください。

`p`キーで全ペット共通の倍率を変えられます。どのペットからでも操作でき、後から開くペットにも反映します。設定は再起動後も保持します。

- 全ペット共通サイズ: `1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0`
- 吹き出しサイズ: `1.0 / 1.5 / 2.0 / 2.5 / 3.0 / 4.0`

吹き出しサイズ・通知・常駐ペットの位置は接続プロファイルごとに保存します。

## セッションペット

接続中のxangiでセッションが実行されると、常駐ペットとは別に、そのセッションを担当するAgentのペットが自動で開きます。同じAgentでも2セッションが同時に動いていれば2体表示します。画像とともにAgent名・セッション名・状態を表示し、ドラッグで移動できます。常駐ペットのAgent選択にかかわらず、接続先インスタンス全体の実行中セッションが対象です。

`x`キーまたはメニューの「接続先」で画面を開き、「表示するセッション」のChat・Web・自動実行を個別に切り替えます。初期値はChat・WebがON、自動実行がOFFです。変更は全接続先のセッションペットにすぐ反映し、再起動後も保持します。すべてOFFにするとセッションペットを隠します。常駐ペットは表示を続けます。常駐側の「見守り中」は実行セッションの件数には含みません。吹き出し・表情・通知にも同じ種類の条件を適用します。種類を変更すると、表示中の吹き出しをクリアします。

完了・中断・エラーなどで実行中でなくなると、そのセッションのペットを閉じます。次の処理を始めると再び開き、接続時にすでに実行中のセッションも表示します。

一時ペットは表示専用です。クリックからの送信や追加の通知は行わず、会話の入力は入力先の常駐ペットから行います。メニューの表示／非表示はすべてのペットに適用します。接続解除ではその接続先の分だけ閉じ、ほかのONインスタンスは継続します。通信断だけでは完了扱いにせず、再接続時にモニターの最新一覧と同期します。自動表示には本体の`/api/sessions/stream?mode=changes`が必要です。

## アプリの複数起動

複数インスタンスの見守りには、通常はアプリを一つ起動すれば十分です。ビルド版は同じMacで複数起動でき、各アプリがONの接続先を表示します。

```bash
open -n -a /Applications/xangi-pets.app
open -n -a /Applications/xangi-pets.app
```

内蔵サーバのポートは `7895` から空いている番号へ自動でずれます。実際のポートはメニューで確認できます。

`npm run tauri dev` は Vite の固定ポート `1420` を使うため、同時に複数起動できません。

## 独自ペットを追加する

Agentを選択した接続先では、そのAgentのworkspace内を優先して読み込みます。標準配置は次のとおりです。Macでpetsを動かし、別マシンでxangiを動かしている場合は、xangi側のworkspaceへ置きます。

```text
<Agent workspace>/assets/xangi-pets/
├── pet.json
└── spritesheet.webp
```

`pet.json`の例:

```json
{"id":"my-pet","displayName":"My Pet","spritesheetPath":"spritesheet.webp"}
```

接続設定の「Agentのスプライト配置先」はworkspace相対ディレクトリです。同じworkspaceを使うAgentで別の画像にしたい場合は、それぞれ別の配置先を指定します。画像を取得できなければ理由を表示し、同梱の`xangi`を使います。画像の変更はAgentまたはworkspace内のファイルで行います。Agentが削除された場合は接続・送信をエラーにします。画像の変更は再起動または接続先の再選択で読み込み直します。

workspace画像は本体のファイルAPI経由で取得します。`pet.json`は64 KiB、WebPは16 MiBまでで、スプライトの寸法は下記と同じです。絶対パスや親ディレクトリ参照は使えません。

スプライトシートは透明な1536×1872 WebP、8列×9行、1セル192×208ピクセルです。

互換素材の作成には [openai/skills の hatch-pet](https://github.com/openai/skills/tree/main/skills/.curated/hatch-pet) を利用できます。

## トラブルシューティング

### ペットが画面外へ出た

メニューバーまたは通常アプリメニューから「ペットを画面中央に戻す」を選びます。

### メニューバーのアイコンが見つからない

Dock から xangi-pets を選び、画面左上の通常アプリメニューを使います。主要操作は両方のメニューにあります。

### 接続済みにならない

xangi が起動していることと、指定した URL をこの Mac から開けることを確認してください。別マシンの場合は LAN／Tailscale の到達性も確認します。Web UI なしの構成では xangi 側の `XANGI_EVENTS_SERVER_ENABLED=true` が必要です。

### ペットからメッセージを送れない

xangi の `POST /api/pet/inbox` 対応版が必要です。グローバル IP 経由で公開した xangi に接続する場合は、xangi と xangi-pets の両方に同じ `XANGI_PET_INBOX_TOKEN` を設定します。loopback、LAN、Tailscale からの接続では通常この設定は不要です。

### macOS がアプリを開かない

[インストール手順](INSTALL.md) の Gatekeeper 対応を参照してください。

### イベント連携を詳しく確認したい

[イベント仕様](EVENTS.md) を参照してください。

## エラー後の表情

悲しい表情はエラー受信から約30秒で通常に戻ります。別の会話が処理・応答中なら、その動きを優先します。エラーの吹き出しは表情が戻っても残るので、内容を確認できます。

## 接続する

初回起動時に接続先の追加画面が開きます。名前と xangi のイベント API URL を入力し、その xangi で Web UI も利用するか選びます。

- 同じ Mac の標準構成: `http://localhost:18888`
- 別マシン: LAN または Tailscale から到達できる `http://` / `https://` URL
- Web UI なし: xangi 側で `XANGI_EVENTS_SERVER_ENABLED=true` を設定し、「Web UI も利用する」を OFF

接続先はプロファイルとして保存され、`x` キーまたはメニューの「接続先」から追加・選択・編集・切断できます。複数の xangi-pets を起動した場合も、保存済みプロファイルは共有されます。

xangi-pets は SSE 接続に成功すると「接続済み」、切断時は「再接続中」と表示します。xangi が復帰すると自動で再接続します。

接続先 URL は `http://` または `https://` のみ受け付けます。ユーザー情報を含む URL は拒否し、query と fragment は保存前に取り除きます。

## 基本操作

- ペットをクリック、または `t`: xangi にメッセージを送る
- ドラッグ: ペットを移動する
- 吹き出しをクリック: 吹き出しを閉じる
- `x`: 接続先を選択・設定する
- `c`: ペットを選ぶ
- `p`: ペットの大きさを切り替える
- `b`: 吹き出しの大きさを切り替える
- `h` または `?`: ヘルプを表示・非表示にする

透明な領域はクリックを背後のアプリへ通します。`1`〜`9` は開発時のアニメーション確認用です。

## メニュー

起動中は macOS のメニューバーに xangi-pets が常駐します。同じ主要操作は、Dock で xangi-pets を選択したときの通常アプリメニューからも利用できます。

- ペットを表示／隠す
- ペットを画面中央に戻す
- xangi に話しかける
- Web Chat をアプリ内または既定ブラウザで開く
- 接続先を設定する
- 通常応答、完了メッセージ、システム通知を切り替える
- ペットと吹き出しの大きさを変える
- ヘルプを表示する／アプリを終了する

自動徘徊や手動配置、モニター構成の変更でペットが画面外へ出た場合は「ペットを画面中央に戻す」を選んでください。起動時にもペットがほとんど見えない位置なら、自動的に現在のモニター中央へ戻ります。

## 通知と吹き出し

通常応答と完了メッセージの吹き出しは別々に切り替えられます。会話中の表示を止めて、完了時だけ確認する使い方もできます。

macOS のシステム通知は初期状態で OFF です。ON にしたあとに開始された turn の完了またはエラーだけを 1 回通知します。再接続時に届いた過去イベントは通知しません。最初の通知時に macOS の許可ダイアログが出る場合があります。

長文は 1 ページ 4 行で表示し、応答完了後に 4 秒間隔でページを送ります。最終ページのあと先頭へ戻ります。

## ペットと表示サイズ

同梱の `xangi` は追加設定なしで使えます。`c` キーで利用可能なペットを選びます。

- ペットサイズ: `0.5 / 0.8 / 1.1 / 1.5 / 2.0`
- 吹き出しサイズ: `1.0 / 1.3 / 1.6 / 2.0 / 2.5`

サイズや通知設定、画面上の位置は接続プロファイルごとに保持されます。

## 複数起動

ビルド版は同じ Mac で複数起動できます。異なる xangi やキャラクターを並べて利用できます。

```bash
open -n -a /Applications/xangi-pets.app
open -n -a /Applications/xangi-pets.app
```

内蔵サーバのポートは `7895` から空いている番号へ自動でずれます。実際のポートはメニューで確認できます。

`npm run tauri dev` は Vite の固定ポート `1420` を使うため、同時に複数起動できません。

## 独自ペットを追加する

Codex `hatch-pet` 互換の素材を次のどちらかへ配置します。上のパスが優先されます。

```text
~/.xangi/pets/<pet-name>/
~/.codex/pets/<pet-name>/
├── pet.json
└── spritesheet.webp
```

スプライトシートは透明な 1536×1872 WebP、8 列×9 行、1 セル 192×208 ピクセルです。起動後に `c` キーを押すと追加したペットを選べます。

探索先を限定する場合は `XANGI_PET_DIR` を指定します。この場合、ほかの探索パスと同梱ペットは使われません。

互換素材の作成には [openai/skills の hatch-pet](https://github.com/openai/skills/tree/main/skills/.curated/hatch-pet) を利用できます。

## トラブルシューティング

### ペットが画面外へ出た

メニューバーまたは通常アプリメニューから「ペットを画面中央に戻す」を選びます。

### メニューバーのアイコンが見つからない

Dock から xangi-pets を選び、画面左上の通常アプリメニューを使います。主要操作は両方のメニューにあります。

### 接続済みにならない

xangi が起動していることと、指定した URL をこの Mac から開けることを確認してください。別マシンの場合は LAN／Tailscale の到達性も確認します。Web UI なしの構成では xangi 側の `XANGI_EVENTS_SERVER_ENABLED=true` が必要です。

### ペットからメッセージを送れない

xangi の `POST /api/pet/inbox` 対応版が必要です。グローバル IP 経由で公開した xangi に接続する場合は、xangi と xangi-pets の両方に同じ `XANGI_PET_INBOX_TOKEN` を設定します。loopback、LAN、Tailscale からの接続では通常この設定は不要です。

### macOS がアプリを開かない

[インストール手順](INSTALL.md) の Gatekeeper 対応を参照してください。

### イベント連携を詳しく確認したい

[イベント仕様](EVENTS.md) を参照してください。
